PLACE YOUR CERTIFICATE TEMPLATE PDF HERE
========================================

Save the PDF file in this folder with the name:

    template.pdf

The app will fetch it from "/template.pdf" at runtime.

If you want to use a different filename or path,
change `pdfTemplatePath` in src/config.js.

Make sure the PDF has exactly ONE page and is sized
the same as your printer paper (A4 by default).
